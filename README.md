## 🚀 Featured Projects

### 1. RecoverIQ — AI Revenue Recovery Decision Engine
An AI-powered decision engine that helps merchants identify effective payment recovery strategies using predictive analytics, policy guardrails, and AI-generated explanations.

**Technologies:** Python, FastAPI, PostgreSQL, React, TypeScript, AI/ML

### 2. Image-to-Video Multi-Agent Pipeline
An automated multi-agent system that transforms images into engaging videos using AI-powered image analysis, intelligent selection, storyboarding, code generation, and video rendering.

**Technologies:** Python, LangGraph, LangChain, Google Gemini, React, TypeScript, Remotion, ChromaDB

### 3. Bengaluru FC Recruitment Intelligence
A data-driven football scouting and recruitment analytics platform examining historical transfers, player pathways, market valuations, squad composition, and recruitment needs.

**Technologies:** Python, Pandas, Matplotlib, ReportLab

### 4. AI Resume Screening System
An AI-powered resume screening application that extracts resume information, evaluates candidates against job descriptions, and generates structured candidate assessments.

**Technologies:** Python, LLMs, PDF Processing, Google Sheets

### 5. Deepfake Detection
A computer vision project designed to identify potential deepfake manipulations in video frames using image processing and machine learning techniques.

**Technologies:** Python, PyTorch, OpenCV, NumPy

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/ayush2005k/YOUR-PORTFOLIO-REPOSITORY.git
cd YOUR-PORTFOLIO-REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
